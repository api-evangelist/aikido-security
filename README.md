Aikido Security is a developer-first all-in-one application security platform that consolidates SAST, SCA, secret detection, container scanning, IaC scanning, CSPM, DAST, API security, malware detection, cloud posture, and AI pentesting into a single product designed for engineering teams. Aikido exposes a public REST API at apidocs.aikido.dev covering issues, code repositories, cloud resources, containers, domains and APIs, compliance (SOC2, ISO 27001, NIS2, CIS), custom SAST rules, AI pentesting, task tracking, webhooks, user and team management, Zen app-protection configuration, and activity logging.

## APIs

### Aikido Security REST API

Aikido Security's REST API provides programmatic access to the Aikido platform across issues and findings, code repositories and SBOM export, cloud resources (AWS, Azure, GCP, Kubernetes), container registries and image scans, domains and API surface, compliance frameworks (CIS, ISO 27001, NIS2, SOC2), custom SAST rules (Semgrep), AI pentesting drafts and assessments, task tracking integrations, webhooks, teams and users with permissions, Zen app-protection (bot protection, IP blocking, threat configurations), and activity logs with PDF export. Authentication is via access tokens issued through the authorization endpoint.

- **Human URL:** [https://apidocs.aikido.dev/reference/introduction](https://apidocs.aikido.dev/reference/introduction)
